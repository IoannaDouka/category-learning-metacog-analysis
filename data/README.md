# Data

Download the behavioral data from Zenodo ([https://zenodo.org/records/10155670](https://zenodo.org/records/10155670), DOI: `10.5281/zenodo.10155670`) and place all six CSV files in this directory:

- `task_data_initial_test.csv`
- `task_data_retest_1.csv`
- `task_data_retest_2.csv`
- `questionnaire_data.csv`
- `questionnaire_overall_scores.csv`
- `questionnaire_subscale_scores.csv`
